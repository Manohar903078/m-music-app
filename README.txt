M MUSIC ANDROID APP (shows your Blogger page)

1. Open app/src/main/res/values/strings.xml and replace YOUR-BLOG with your Blogger name.
2. Create a PUBLIC GitHub repo (example: m-music-app) and upload ALL these files (keep the .github folder).
3. Open the Actions tab. "Build APK and publish release" runs by itself (about 5 minutes).
4. When it finishes, go to the repo > Releases. The APK is there.
   Permanent download link:
   https://github.com/Manohar903078/m-music-app/releases/latest/download/app-debug.apk
